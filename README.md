# Rpixel

Rpixel is a mobile-first H5 puzzle game prototype built with Vite, TypeScript, and Phaser.

## Local Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run build
```

## Deployment

The repository includes a GitHub Actions workflow that builds and deploys `dist/` to GitHub Pages when `main` is updated.
